## ModalTrait

Neben dem herkömmlichen öffnen eines Modals (z.B. https://getbootstrap.com/docs/5.3/components/modal/), wird mit diesem Trait ein Modal mit Livewire (auch über den Event Listener außerhalb von Livewire) geöffnet.

#### Definierte Variabelen

- $modalName
- $modalTitle
- $modalSwitch

- $modalCols
- $modalItem
- $modalSwitch
